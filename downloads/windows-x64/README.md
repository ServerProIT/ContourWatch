# Windows-агент 0.1.1

[Скачать ContourSetup.exe](https://github.com/ServerProIT/ContourWatch/raw/refs/heads/main/downloads/windows-x64/ContourSetup.exe)

Один x64 EXE содержит службу, трей и оригинальную иконку. Требуется .NET Framework 4.8+. Адрес сервера и токен вводятся при установке: **в файле нет вашего токена, адреса monitor.serv-pro.ru, учётных данных устройств или аппаратных данных**. Они не включаются сборочным сценарием. Исходники: agent/windows, installer/build.ps1 и installer/Setup.cs.

В 0.1.1 исправлен сбой старта службы без консоли: старый агент вызывал Console.OutputEncoding до подключения к SCM и мог завершиться с IOException «Неверный дескриптор». Теперь служебный старт не обращается к кодировке консоли, а консольные режимы обрабатывают отсутствие дескриптора. Ошибка установщика содержит цепочку причин и native Win32 code. Проверка параметров выполняется до остановки ранее установленной службы. Тихое удаление не показывает блокирующее окно.

Установщик пока **без Authenticode-подписи издателя**. SHA256SUMS.txt помогает сверить точные байты с опубликованной версией, но не заменяет цифровую подпись и не гарантирует отсутствие ошибок. Не отключайте антивирус/SmartScreen ради установки. Сначала испытайте на одном тестовом компьютере, затем расширяйте развёртывание. Не используйте этот EXE для неподписанных автоматических обновлений.

Проверка в PowerShell:

```powershell
Get-FileHash .\ContourSetup.exe -Algorithm SHA256
```

Сравните с [SHA256SUMS.txt](SHA256SUMS.txt). Если значения отличаются, не запускайте файл. При замене файла репозитория checksum меняется вместе с ним; для фиксированной версии используйте ссылку на конкретный Git commit.

## Повторная установка после ошибки запуска

1. Закройте старый установщик и значок трея, если он работает.
2. Запустите новый ContourSetup.exe от администратора.
3. Сохраните тот же HTTPS-адрес. Если уже выданы индивидуальные credentials, повторную регистрацию включать не нужно.
4. Если регистрации ещё не было или токен истёк, создайте новый токен в панели и включите повторную регистрацию.
5. Нажмите «Установить / сохранить», затем проверьте `Get-Service ContourWatch`. Журнал: `C:\ProgramData\ContourWatch\agent.log`.

Токен, использованный для отдельного тестового подключения, мог исчерпать лимит. Публично его не публикуйте. Старый идентификатор/очередь сохраняются при обычной переустановке; при повторной регистрации выдаётся новая идентичность. На сервере нет механизма произвольного исполнения команд.

Аппаратные smartctl/LibreHardwareMonitor DLL/драйвер не вложены; без них SMART/CPU/fans явно недоступны. Исправление старта службы не означает квалификацию этих компонентов или всех версий Windows Server.
