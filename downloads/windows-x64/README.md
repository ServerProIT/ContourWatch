# Windows-агент 0.1.2

[Скачать ContourSetup.exe](https://github.com/ServerProIT/ContourWatch/raw/refs/heads/main/downloads/windows-x64/ContourSetup.exe) · [SHA256SUMS.txt](SHA256SUMS.txt)

Один x64 EXE содержит службу, трей, оригинальную иконку и LibreHardwareMonitor 0.9.6. Требуется .NET Framework 4.8+. Адрес и токен вводятся при установке, в публичном файле нет конфигурации, токенов и телеметрии пользователей. Драйвер PawnIO и smartctl не включены. [Установка датчиков, обновление и диагностика](../../docs/AGENT-0.1.2.md).

В 0.1.2 исправлены TLS 1.2 в проверке соединения, обновление при работающем трее, отображение отзыва доступа; добавлены раздельные CPU/NVIDIA GPU и структурированная диагностика. При смене только конфигурации неизменённый трей не завершается. При обновлении его файла установщик завершает только трей из каталога установленного агента; запустите значок снова вручную либо при следующем входе.

Проверка файла:

```powershell
Get-FileHash .\ContourSetup.exe -Algorithm SHA256
```

Сравните результат с SHA256SUMS.txt. Сборка пока без Authenticode-подписи издателя; checksum не заменяет подпись. Не отключайте защиту Windows для установки. Не используйте этот EXE для автоматических неподписанных обновлений.

Тесты реальной службы на чистой Windows VM запускаются в [GitHub Actions](https://github.com/ServerProIT/ContourWatch/actions/workflows/verify.yml), включая обновление 0.1.1 → 0.1.2 с открытым треем. Это не сертификация всех ОС/датчиков. Аппаратные измерения конкретной Ryzen/RTX 5070 системы требуют проверки на ней.
