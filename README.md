# Контур / ContourWatch

Собственная система мониторинга оборудования Windows и Linux для локальной сети. Панель **0.1.1**, Windows-агент **0.1.1**, Linux-агент **0.1.0** — для стенда и пилотной проверки. Полная готовность к промышленной эксплуатации не подтверждена.

## Ubuntu в Proxmox + Nginx Proxy Manager

Основной способ развёртывания: отдельная Ubuntu-ВМ с Docker, HTTPS на существующем NPM на другом сервере. [Пошаговая инструкция и поля Proxy Host](docs/UBUNTU-NPM.md).

```sh
sudo git clone https://github.com/ServerProIT/ContourWatch.git /opt/contourwatch
cd /opt/contourwatch/deploy
sudo cp .env.example .env
sudo nano .env
# PUBLIC_URL=https://ваше-имя, APP_BIND_IP=приватный-IP-ВМ,
# TRUSTED_PROXY_IPS=IP-отдельного-NPM
cd ..
sudo sh deploy/up.sh
```

Требуется Docker Engine с Compose plugin. NPM направляет HTTP на IP панели:8080; пользователи и агенты обращаются к внешнему HTTPS-имени. Ключ администратора: `cd deploy && sudo docker compose exec server cat /data/admin.key`. Порт 8080 разрешайте только серверу NPM через Proxmox/network firewall. Caddy и сертификаты внутри контейнера панели не нужны.

База и разные случайные ключи ролей сохраняются в постоянном volume `contourwatch-data`. Online backup: `sudo sh deploy/backup.sh /путь/к/защищённым/копиям`. Не удаляйте volume при обновлении; не используйте `down -v` на своей ВМ.

Проверено на Ubuntu 24.04 в [GitHub Actions](https://github.com/ServerProIT/ContourWatch/actions/runs/43384195374): 70 серверных тестов, 15 Linux logic tests, сборка/запуск контейнера, сохранение после restart и backup/restore. [Отчёт 0.1.1](docs/DEPLOYMENT-VALIDATION-0.1.1.md). Реальные NPM, Proxmox firewall и reboot вашей ВМ ещё нужно проверить.

## Что уже работает

- API регистрации и приёма показателей; ограниченные регистрационные токены, отдельные отзываемые учётные данные устройств.
- SQLite с WAL, миграциями, защитой от повторных пакетов, текущими значениями, историей и часовыми агрегатами.
- Панель на русском: светлая и тёмная темы, поиск, группы, сортировка, карточка устройства, графики, события, обслуживание, подтверждение, роли администратора и наблюдателя.
- Windows x64: служба C#/.NET Framework 4.8, самостоятельный трей, один EXE-установщик, тихая установка, DPAPI, ограниченная очередь, повторная доставка и независимые сборщики с тайм-аутами.
- Linux: Python 3.9+, служба systemd, самостоятельный трей на PySide6, очередь, регистрация, SMART и lm-sensors через отдельные процессы.
- Собственные SVG-иконки панели и агента, ICO для Windows.

## Старт сервера без Docker

Установите **Node.js 24.11.x** (испытано с 24.11.1). Зависимости npm не нужны.

```sh
node server/main.mjs
```

Откройте `http://127.0.0.1:8080`. Ключи администратора/наблюдателя генерируются отдельно в `data/admin.key` и `data/viewer.key` и сохраняются между запусками. Возможны явные ADMIN_KEY/VIEWER_KEY или ADMIN_KEY_FILE/VIEWER_KEY_FILE; одновременно значение и файл одной роли запрещены. В Linux защитите каталог data правами 0700; в Windows ограничьте ACL учётной записью сервера и администраторами. Ключи доступа пока общие для роли, персональные учётные записи и аудит действий операторов не реализованы.

Сервер по умолчанию доступен **только через loopback**. Для работы агентов необходим HTTPS через обратный прокси и доверенный сертификат. Пример: [развёртывание](docs/DEPLOYMENT.md).

```sh
node server/main.mjs --demo
```

Демо использует отдельную `demo.db`, показывает явное предупреждение и моделирует устройства. Для производственной базы запускайте без `--demo`. Не подключайте настоящие устройства к демонстрационному серверу.

## Агенты

Windows: [скачайте готовый установщик и проверьте SHA256](downloads/windows-x64/README.md) либо соберите `installer/build.ps1` в PowerShell. Получится `dist/windows-x64/ContourSetup.exe`; запустите от администратора, укажите HTTPS-адрес сервера и токен из панели. Установщик содержит службу, трей и иконку. Требует заранее установленный .NET Framework 4.8; runtime и сторонние драйверы не вложены.

Linux: [установка и ограничения](docs/LINUX.md). Цели пилотной поддержки: Ubuntu 22.04/24.04, Debian 12/13, Rocky Linux 9; реальные проверки на этих дистрибутивах ещё не выполнены.

## Проверки

```sh
node --test tests/*.test.mjs
python3 tests/linux_test.py
node tests/load.mjs
```

Windows, после сборки:

```powershell
.\dist\windows-x64\ContourAgent.exe --self-test
node tests/windows-e2e.mjs
```

Сквозной тест использует отдельный временный каталог и loopback API, не устанавливает службу. Исключение HTTP допускается агентом только при явном локальном тестовом режиме и только для loopback. Обычный установщик принимает HTTPS.

## Границы готовности

**Автоматическая установка обновлений через GitHub пока не реализована.** Переключатель разрешения и окно UTC в настройках — задел для канала обновления, они не запускают установку. Нужны доверенная подпись, отдельный процесс обновления, проверка запуска и испытанный откат. Данные о версии агент передаёт, статус ограничения показывается в карточке.

**SMART и аппаратные датчики Windows не включены в поставку.** Есть адаптер smartctl JSON и изолированный адаптер LibreHardwareMonitor; перед использованием требуется выбрать и испытать конкретную версию, драйвер и оборудование. Без них панель показывает «Не поддерживается». Не отключайте защиту Windows ради датчиков.

Не проверены: установка/удаление и перезагрузка со службой агента, работа графического трея, Server 2012/2012 R2/2016/2019/2022, Linux systemd и реальное Linux-оборудование, RAID/USB, обновление агента поверх установленной версии. Исходный [отчёт 0.1.0](docs/VALIDATION.md) дополняется [проверкой развёртывания 0.1.1](docs/DEPLOYMENT-VALIDATION-0.1.1.md).

## Устройство проекта

| Каталог | Содержание |
|---|---|
| `server` | API, события, SQLite, миграции |
| `web` | Автономный интерфейс, темы, оригинальные SVG |
| `agent/windows` | Служба, изолированные сборщики, трей |
| `agent/linux` | Служба Python, systemd, графический трей |
| `installer` | Исходник EXE-установщика и сборка |
| `deploy` | Docker Compose под внешний NPM, запуск и online backup |
| `tests` | Логика, HTTP, сквозной Windows-тест и нагрузка |
| `docs` | Развёртывание, совместимость, ограничения, результаты |

Публичность репозитория сама по себе не является лицензией. Лицензия проекта владельцем пока не выбрана. Сторонние компоненты: [THIRD_PARTY.md](docs/THIRD_PARTY.md).
