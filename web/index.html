КАРТОЧКА УСТРОЙСТВА

Подключить устройство

Токен используется только при регистрации. Затем устройство получает собственные учётные данные.

Windows: запустите ContourSetup.exe и укажите адрес сервера и токен.

Linux: выполните install.sh из поставки, затем configure.

Адрес сервера должен начинаться с https://. Внутренний центр сертификации добавляется в доверенное хранилище ОС.

Отозвать доступ устройства?

Агент больше не сможет передавать данные. История сохранится. Для нового подключения потребуется повторная регистрация.
