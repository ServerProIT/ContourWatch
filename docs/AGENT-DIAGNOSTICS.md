# Логи и диагностика агентов 0.2.1

Windows: нажмите правой кнопкой значок «Контур» в трее → **Логи и диагностика…**. Окно также доступно через ярлык **ContourWatch logs and diagnostics** в меню «Пуск» или `ContourTray.exe --logs`.

Окно показывает снимок каждого сборщика и ограниченный журнал последних событий. Для датчика указаны имя, тип, источник, время измерения, состояние, причина недоступности, тип ошибки и время опроса. Включены сведения о PawnIO и результате smartctl, если их сообщает сборщик. Ошибка, отсутствие поддержки, запрет доступа и устаревшее значение не подменяются нулём. Повторение одного состояния не заполняет журнал; изменение и восстановление записываются отдельно.

**Обновить** перечитывает локальные файлы. **Автообновление (5 с)** включается отдельно. При остановленной службе или паузе сохраняются последние данные с отметкой времени. Первые данные появляются после опроса; для SMART интервал может достигать 15 минут. Само окно не запускает повторный опрос оборудования и не требует прав администратора.

**Сохранить в TXT…** создаёт читаемый отчёт. **Сохранить архив ZIP…** добавляет снимок JSON и журналы для разбора. Место и имя файла выбираются в собственном окне агента. Замена существующего файла требует подтверждения. Запись атомарная: ошибка сохранения не обрезает прежний файл.

Конфигурация, регистрационные токены, пароль/секрет устройства, очередь телеметрии и исходный SMART с серийными номерами в экспорт из трея не включены. Имена датчиков, модели оборудования, локальные пути устройств и время событий остаются в отчёте; перед передачей отчёт можно просмотреть. Агент сам никуда не отправляет сохранённый архив.

Локальные читаемые файлы Windows: `%ProgramData%\ContourWatch\public\diagnostics.json` и `diagnostics.log` с ротацией (до трёх архивов по 256 КиБ). Защищённые конфигурация и очередь остаются в прежнем закрытом каталоге.

## Тема приложения

Светлая, тёмная и системная темы распространяются на окна состояния, настройки, диагностики, собственный выбор файла, сообщения и подтверждения, поля, списки, кнопки, чекбоксы, меню и полосы прокрутки. Заголовки Windows получают цвет приложения через DWM. Выбор темы применяется ко всем открытым окнам агента. Системные запросы UAC не являются окнами агента.

## Linux

В необязательном трее PySide6 есть пункт **Логи и диагностика…**, просмотр и сохранение TXT/ZIP. Диалог сохранения использует тему приложения.

```sh
python3 /opt/contourwatch/agent.py --logs
python3 /opt/contourwatch/agent.py --diagnostics "$HOME/contour-diagnostics.txt"
python3 /opt/contourwatch/agent.py --diagnostics "$HOME/contour-diagnostics.zip"
```

Эти команды только читают `public/` и не требуют останавливать службу. По умолчанию существующий файл не перезаписывается. Журнал ограничен 256 КиБ с двумя архивами. Снимок содержит последние результаты сборщиков, включая причины ошибок; исходная очередь и конфигурация исключены.
