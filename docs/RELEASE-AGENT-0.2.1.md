# Агент 0.2.1 / панель 0.4.1

Панель 0.4.1 объединяет персональную Главную, полноэкранную карточку, конструктор целых блоков, перенос/изменение размеров строк и столбцов таблиц, отдельные настройки аккаунтов и удаление отозванных устройств. Одновременно открывается одно меню фильтра, фон тёмной страницы заполнен целиком.

Агент 0.2.1 добавляет просмотр и сохранение локальных логов и снимка диагностики. В отчёте видны причины отсутствия отдельных показателей. Windows-трей экспортирует TXT/ZIP без повышения прав; Linux поддерживает трей и команды экспорта. Тёмная тема распространяется на всё приложение, включая собственное окно сохранения и сообщения. [Инструкция по диагностике](AGENT-DIAGNOSTICS.md).

Установка MSI поверх версии 0.2.0 сохраняет сервер, регистрацию и очередь. После установки откройте новый значок трея либо ярлык логов. Подписанный манифест совместим с обновлениями агентов 0.2.0; обновление выполняется при включённой политике панели в разрешённое окно. Подпись манифеста не является Authenticode-подписью MSI.

PawnIO не переустанавливается и не включается автоматически. Если CPU/вентиляторы не читаются из-за отсутствия драйвера, отчёт показывает причину. Само наличие новой диагностики не добавляет поддержку датчиков, не предоставляемых оборудованием или драйвером.

Проверки включают Windows-сборку, ротацию/редактирование секретов, отсутствие конфигурации и очереди в экспорте, восстановление состояния датчика, настоящее WinForms-окно и цвета элементов в обеих темах. CI проверяет установку, repair, обновление и откат MSI в изолированной ВМ. Linux: тесты диагностики, сборщиков и подписанного обновления; локальная ручная проверка окна выполнена на Windows.
