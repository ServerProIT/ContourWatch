Дата: 13 ноября 2026 года. Локальный Windows-хост: NT 10.0 build 26200, x64; Node.js 24.11.1; встроенный Framework CSC; Python 3.12 из среды разработки. Название ОС из legacy ProductName может показывать Windows 10 даже на новых сборках, поэтому фиксируется также номер build.

## Реальная доступность показателей на текущем компьютере

| Источник | Доступность |
|---|---|
| Физическая RAM | Получены общий, доступный, используемый объёмы и процент |
| Два фиксированных тома | Получены размер, свободное и занятое место |
| CPU / вентиляторы | Не поддерживается в данной поставке: квалифицированная библиотека не установлена |
| SMART | Не поддерживается в данной поставке: smartctl.exe не установлен |

Результаты замеров, локальные ключи и базы рабочего компьютера в публичный репозиторий не включены.

## Нагрузка

Повторный прогон после изменения агрегатов: 300 имитируемых устройств, 10 циклов, 30 параллельных отправителей, 40 метрик в пакете. **3000 пакетов / 120 000 метрик**, все пакеты подтверждены API, число строк проверено в БД.

Время прогона 9.44 с; p50 73.36 мс; p95 193.41 мс; p99 266.33 мс. Файл БД ~27.2 МБ, WAL ~4.2 МБ на момент измерения. Сеть loopback, один текущий компьютер, свежая база, тестовые данные. Результат не распространяется автоматически на медленное оборудование, WAN, TLS-прокси, 30-дневную базу или длительную нагрузку.

## Исправлено по результатам проверок

- UTF-8 вывода дочерних процессов: первоначально русские названия искажались.
- Тайм-аут проверяется управляемым тестовым процессом; ping в песочнице завершался раньше тайм-аута и был непригоден как тест зависания.
- Повтор регистрации использует сохранённый UUID и индивидуальный случайный секрет: потеря ответа не расходует второй токен и не создаёт дубль устройства.
- Повторный пакет обновляет время контакта, но не историю и агрегаты.
- Устаревшая CPU-метрика не становится свежей из-за нового heartbeat.
- Агрегаты обновляются при приёме, без повторного разбора всей истории раз в час.
- SMART-код возврата трактуется как битовая маска, а не просто «не ноль = программа сломалась».
- Недоступные значения не превращаются в ноль; 0 RPM не создаёт аварию вентилятора.

## Пока не проверено или не реализовано

- Любая установка/удаление службы, старт после перезагрузки, восстановление SCM/systemd, графический трей.
- Server 2012/2012 R2 и остальные целевые Windows на отдельных машинах; Linux на настоящих целевых дистрибутивах.
- Реальные HDD/SATA SSD/NVMe/SAS, RAID и USB; библиотека датчиков/драйвер, Secure Boot/HVCI.
- Docker Compose/TLS на выделенном сервере, резервное восстановление.
- Безопасный updater с подписью, установкой и откатом — пока не реализован; не включать неподписанные автообновления.
- Установщик unsigned, .NET/аппаратные сторонние компоненты не упакованы внутрь, Linux GUI требует отдельного PySide6.
- Личные учётные записи операторов, аудит, автоматическое обнаружение клонов, Redfish — пока не реализованы.
- Длительная нагрузка и стабильность на реальном парке, размер/очистка базы после накопления истории.

Следующий критерий допуска: испытание всех пунктов из [ROADMAP.md](ROADMAP.md) в изолированном стенде. Обещание «программных ошибок и зависаний не будет» на основании этих проверок было бы недостоверным.
